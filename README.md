# Ankit Anand — personal CV site

Live at **https://chuggu12.github.io** (GitHub Pages, served from `main`).

A hand-built, dependency-free recreation of my Wix portfolio: plain HTML, CSS and JavaScript.

| Page | File |
| --- | --- |
| Home (about, accolades, skills, experience, portfolio, publication, contact) | `index.html` |
| Projects (filterable list) | `projects.html` |
| Articles & publications | `articles.html` |
| Open source (GitHub repositories) | `open-source.html` |

Shared styles are in `assets/css/style.css` (page-specific files sit next to it), behaviour in `assets/js/main.js`.

To preview locally, open `index.html` in a browser. To update the live site, commit and push to `main`.
