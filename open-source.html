Rozi: GenAI Gig Worker Companion

Rozi is a multilingual, mobile-first web app (PWA) for gig and informal workers in India. It covers earnings tracking, safety alerts, welfare-scheme awareness, document help and grievance-letter drafting. Gemini handles translation and simplification, while all calculations run in deterministic Python.

Highlights

  • Supports English, Hindi, Tamil and Punjabi, with source-cited JSON data on welfare schemes (e-Shram, PM-JAY, PMSBY), helplines and legal references
  • Gemini model-failover chain with a deterministic fallback for every AI feature, plus guards that reject AI output adding rupee figures or links
  • PII redaction (Aadhaar/PAN/phone) on both client and server, CSP headers and rate limiting; personal data is kept only in the browser

Built with

  • Python
  • FastAPI
  • Pydantic
  • Jinja2
  • httpx
  • JavaScript
  • HTML
  • CSS
  • Google Gemini API
  • Open-Meteo API

SAFAR: AI Road Safety Prototype

A team hackathon prototype, written in R, for SAFAR (Smart AI for Accident Reduction), a road safety system for India. It sketches how to combine accident, weather, blackspot and telematics data, predict accident risk with XGBoost and LIME, and show alerts in a Shiny/Leaflet dashboard.

Highlights

  • Plans to combine four data sources: MORTH accident reports, IMD weather, NHAI blackspots and driver telematics
  • Rule-based alert modules for EV proximity, dark zones (lux thresholds), landslide risk on hilly roads and driver fatigue
  • Built for a hackathon at NIT Rourkela by Ankit Anand, Vishwajeet Rawat and Ishita Rawat

AI Financial Document Processing System

A MUJ Hackathon project in R. It uses Tesseract OCR to read scanned financial documents (salary slips, Form 16/ITR, cheques and bank statements), sorts them by type with keyword rules, extracts key fields, groups transactions into categories and exports ggplot2 charts and an Excel report.

Highlights

  • Handles four document types: salary slips, ITR-16 forms, cheques and bank statements
  • Cleans up images with magick (grayscale, contrast, normalization) before OCR, then uses regex to pull out fields such as PAN, net pay and cheque amounts
  • Sorts bank transactions into 13 categories and saves salary-trend, expense-category and monthly cash-flow charts plus an Excel workbook

Tobacco Marketing Data QA/QC

Work from a PAC internship with Vital Strategies' tobacco unit. An R Markdown workflow runs QA/QC on India TERM data on tobacco marketing in social media and news posts. It checks fields against a codebook, standardises categories, verifies URLs, removes duplicates and exports a clean dataset.

Highlights

  • R workflow (tidyverse, janitor, readxl, RCurl) checks columns against a codebook, recodes invalid categories with gsub/setdiff, flags NAs, checks links with url.exists() and removes duplicates with get_dupes()
  • Codebook covers tobacco type, account type, marketing tactic (e.g. surrogate advertising, CSR) and message framing for posts from Indian brands and news outlets
  • Includes a 28-slide “TERM Methodology: Data Cleaning in R” deck covering importing, merging, validating and cleaning, plus India QA/QC and situation-report Excel workbooks (April–May 2024)

Built with

  • R
  • R Markdown
  • Excel

Foreign Aid DEA Panel QA-QC

An R pipeline that builds a panel dataset for 36 African countries for Data Envelopment Analysis of foreign aid efficiency. It reshapes World Bank-style indicator data into Country × Year × Indicator form and checks missing data by country, year and indicator.

Highlights

  • 36 African countries (West, East, Central and Southern Africa) treated as DMUs for DEA
  • Reshapes about 44 indicators, including net ODA received, from wide year columns into long and panel formats exported to Excel
  • Missingness diagnostics: coverage by indicator, country and year, Country × Indicator heatmaps, and a first year with at least 80% complete coverage

Amplitude Modulation Analysis

A Wolfram Mathematica notebook on the theory of amplitude modulation, covering carrier, modulating and modulated signals. It uses Fourier and inverse Fourier transforms to show the carrier and the upper and lower sidebands in the spectrum.

Highlights

  • Worked example: the modulated signal Cos(5x)*[Cos(x)+1], with a carrier at frequency 5 and a modulating tone at frequency 1
  • Spectrum built with FourierTransform, showing the carrier, upper and lower sidebands, and a Dirac delta at zero frequency from the constant component
  • InverseFourierTransform used to recover the original AM waveform from its spectrum

Conic Shapes Drawing Module

A Python module that draws conic sections and other mathematical curves with the turtle graphics library. It uses parametric and polar equations and lets you set the center offset, axes, orientation and color for ellipses, parabolas, hyperbolas, cardioids, roses, spirals and more.

Highlights

  • Draws ellipses, circles, parabolas, hyperbolas and rectangular hyperbolas from parametric equations (for example x = a·sec t, y = b·tan t)
  • Extended set of curves: cardioid, limaçon, rose curve, spiral, astroid, cycloid, epitrochoid, hypotrochoid, lemniscate, cissoid, witch of Agnesi and heart curve
  • Class-based ConicDrawer with axes drawing, plus a mode that runs each shape in its own separate process

  • Python
  • turtle graphics
  • GitHub Actions
